# Security Policy

## Project status and supported versions

Agentic Eval Toy App is an experimental evaluation target and is not intended
for production use. It has no supported production release or guaranteed
security maintenance window. Security fixes are considered on a best-effort
basis for the latest revision of `main`; older commits and deployments are not
supported.

Use synthetic or non-sensitive data only. Do not send personal data,
credentials, confidential reports, or restricted information to the
application or its configured model and tracing services.

## Report a vulnerability privately

Do not open a public GitHub issue or discussion for a suspected vulnerability.

Use GitHub's private vulnerability reporting flow from the repository's
**Security** tab. If that option is unavailable, email
`aipractice@tech.gov.sg` with the subject `Agentic Eval Toy App security
report`.

Include, where possible:

- a description of the vulnerability and its impact;
- the affected commit, version, configuration, or deployment mode;
- minimal reproduction steps or a proof of concept;
- any known mitigations; and
- a safe way to contact you for follow-up.

Do not include real credentials, personal data, restricted information, or
other third-party secrets in the report. If a credential may have been
exposed, revoke or rotate it immediately before reporting.

## What to expect

This project is maintained on a best-effort basis and does not promise an
acknowledgement or remediation SLA. Maintainers will validate the report,
assess its impact, and coordinate remediation and disclosure where possible.
Please allow maintainers an opportunity to investigate before publishing
technical details.

Non-security bugs, hardening suggestions without a vulnerability, and feature
requests should use the public issue tracker.
